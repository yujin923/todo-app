# 📝 Todo App (Login 기반)

React + TypeScript + Vite + Express + MariaDB로 만든<br/>
로그인 기반 개인 Todo 관리 서비스입니다.

## Feature
-회원가입 / 로그인 (JWT 인증)<br/>
-사용자별 Todo 관리<br/>
-Todo 추가 / 완료 체크<br/>
-로그아웃 기능

## Tech Stack
Frontend

-React<br/>
-TypeScript<br/>
-Vite<br/>

Backend

-Node.js<br/>
-Express<br/>
-MariaDB<br/>
-JWT Authentication<br/>

## Project Structure
my-todo-app

|-- src (frontend)<br/>
|-- backend (server + DB)

## Run

### frontend
npm install<br/>
npm run dev<br/>

### backend
cd backend<br/>
npm install<br/>
node server.js
