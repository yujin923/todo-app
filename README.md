#📝 Todo App (Login 기반)

React + TypeScript + Vite + Express + MariaDB로 만든
로그인 기반 개인 Todo 관리 서비스입니다.

## Feature
-회원가입 / 로그인 (JWT 인증)
-사용자별 Todo 관리
-Todo 추가 / 완료 체크
-로그아웃 기능

## Tech Stack
Frontend
-React
-TypeScript
-Vite

Backend
-Node.js
-Express
-MariaDB
-JWT Authentication

## Project Structure
my-todo-app
|-- src (frontend)
|-- backend (server + DB)

## Run

### frontend
npm install
npm run dev

### backend
cd backend
npm install
node server.js
